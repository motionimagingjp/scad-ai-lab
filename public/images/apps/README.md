# アプリカードのスクリーンショット

ここに画像を置くと、トップページの「いま公開しているアプリ」一覧で、
文字アイコン（ス／B／S）の代わりに実際のアプリ画面が表示されます。
置かなければ今まで通り文字アイコンのままです（コード変更不要）。

## ファイル名のルール

ファイル名が**アプリのidで始まっていれば**、拡張子・後ろの文字は自由です。

| アプリ | id（このどれかで始まるファイル名にする） | 例 |
|---|---|---|
| スクアド | `sukuado` | `sukuado.jpg`, `sukuado-screen.png` |
| SCAD Beauty | `beauty` | `beauty.jpg` |
| Tokyo Solo Club | `solo` | `solo.jpg` |

対応拡張子：jpg / jpeg / png / webp

## おすすめの撮り方

- スマホのスクリーンショットをそのまま置いてOK（縦長でも自動で中央トリミングされます）
- 文字が読みやすい、アプリらしさが伝わる画面（トップ画面やチャット中の画面など）を選ぶ
- 個人情報や実際のやり取り内容が写っていないか確認してから置く
